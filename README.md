This project is a console-based Blackjack game written in C that simulates the core mechanics of
the classic casino card game. The player begins with a fixed amount of money, places bets each round, 
and plays against a computer-controlled dealer following standard Blackjack rules. Cards are dealt 
randomly with assigned suits, the dealer’s first card is hidden during the player’s turn, and the player
can choose to hit or stand. Hand values are calculated dynamically with proper handling of Aces, and the
game continues until the player quits or runs out of money. This project demonstrates structured programming
in C, including the use of structs, arrays, functions, and basic game logic.
